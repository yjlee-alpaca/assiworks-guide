# 어시웍스 화면 가이드

권한별 메뉴와 초기 세팅 순서를 담은 안내 문서입니다.
배포 주소는 https://assiworks-guide.vercel.app 입니다.

## 파일 하나뿐입니다

`index.html` 이 가이드 전체입니다. 캡처 이미지도 이 파일 안에 들어 있어서
따로 챙길 자료가 없습니다.

## 고치는 방법

1. `index.html` 을 고칩니다
2. 커밋하고 푸시합니다
3. 푸시하면 배포 주소에 반영됩니다

예전에는 명령줄로 직접 올렸습니다. 2026년 9월 28일에 이 저장소를 배포와 연결했고,
그때부터는 푸시가 곧 배포입니다. 올리는 사람이 누구든 같은 판이 나갑니다.

## 프로토타입과 섞지 않습니다

예전에는 프로토타입 저장소 안에도 같은 파일이 사본으로 들어 있었습니다.
사본 쪽만 오래 방치되어 내용이 뒤처졌습니다. 그래서 가이드는 이 폴더에만 둡니다.

## 이 폴더의 시작점

2026년 9월 28일에 배포 중이던 문서를 그대로 받아 왔습니다.
캡처 57장, 섹션 35개짜리 판입니다.
