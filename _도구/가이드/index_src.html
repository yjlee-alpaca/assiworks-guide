개인 공간과 고객사 공간 전환

한 계정이 개인 공간과 고객사 공간을 함께 가질 수 있습니다. 팀 전환 메뉴에서 사용할 공간을 선택해 전환합니다.

공간을 전환하면 메뉴, 유닛, 자료가 선택한 공간을 기준으로 바뀝니다. 각 공간에서 만든 유닛은 해당 공간에만 표시됩니다.

Root 권한의 관리 주체

Root 권한의 관리 주체는 납품 형태에 따라 다릅니다.

납품 형태Root 권한 관리 주체
클라우드운영사만 Root 화면에 접근합니다. 고객사는 Admin 화면부터 사용합니다.
온프레미스설치를 마친 뒤 Root 계정을 고객사에 전달합니다. 전달한 뒤에는 운영사가 원격으로 접근할 수 없습니다.
Root를 제공하지 않는 경우고객사가 Admin 설정에서 소속 Enterprise를 직접 운영합니다.

로그인한 계정의 권한에 따라 표시되는 화면과 사용할 수 있는 기능이 달라집니다.

유닛 제작 권한 설정

유닛 제작 권한은 고객사와 팀, 두 단계에서 설정합니다.

  1. 고객사의 제작 권한 등급: 운영사가 설정합니다. 사용만으로 설정하면 고객사는 운영사가 배포한 유닛만 사용합니다. 제작 가능으로 설정하면 고객사가 유닛을 직접 만들 수 있습니다.
  2. 팀의 유닛 제작 허용: 고객사가 제작 가능 등급일 때만 설정할 수 있습니다. 제작 허용을 켠 팀에는 Tools, Agents, Flows 메뉴가 표시됩니다.

관리자가 자료를 등록하고 유닛을 만들어 앱에 연결하면, 팀원은 그 앱에서 대화로 유닛을 실행합니다. 단계별로 사용하는 메뉴는 다음과 같습니다.

자료 등록부터 팀원 사용까지

1자료 등록Storage · VDB · Maps · Connections

문서를 올려 VDB에 저장하고, 지도 자료와 연결 정보를 등록합니다.

2유닛 만들기Tools · Operators · Loops · Flows

기능 단위의 Tool을 만들고, 필요한 Tool을 선택해 실행할 Operator를 연결합니다. 여러 단계로 이루어진 작업은 Flow로 구성합니다.

3앱에 연결Apps

팀원이 사용할 앱을 만들고 유닛을 연결합니다. 대화형 + 지도 앱에는 맵셋을 지정합니다.

4팀에 앱 지정Settings › 팀

팀별로 사용할 앱, 팀원, 알림 대상을 설정합니다.

5대화로 요청대화형 · 대화형 + 지도

팀원이 앱에서 업무를 요청하면 내용에 맞는 유닛이 실행됩니다.

6기록 확인Monitoring · Audit Log

실행 내역과 설정 변경 이력을 확인합니다.

유닛은 앱에 연결해야 팀원 화면에 표시됩니다. 유닛을 만든 뒤 앱에 연결하지 않으면 팀원은 해당 유닛을 사용할 수 없습니다.

직접 만든 유닛과 배포받은 유닛

2단계의 유닛은 고객사가 직접 만들거나, 운영사가 유닛 카탈로그에서 배포한 것을 사용합니다. 배포받은 유닛도 3단계부터 같은 순서로 앱에 연결합니다.

유닛 간 연결 관계

유닛역할연결 대상
Tool한 가지 기능을 수행하는 가장 작은 단위입니다.Operator에 장착하거나 Flow의 단계로 추가합니다.
Operator요청을 해석하고, 장착된 Tool 중 필요한 것을 선택해 실행합니다.앱에 연결하거나 Flow의 단계로 추가합니다. 맵셋을 연결하면 결과를 지도 화면에 표시합니다.
Loop컨테이너 작업 환경에서 파일을 만들고 코드를 실행하며 결과를 수정합니다.Operator가 호출하거나 단독으로 실행합니다. Flow에서는 Operator에 연결해서만 사용합니다.
Flow여러 유닛을 정해진 순서와 조건에 따라 실행합니다.앱에 연결하거나, 예약해 정해진 시간에 실행합니다.

화면과 문서에서 사용하는 용어를 정리했습니다. 메뉴 이름은 화면 표기를 그대로 사용합니다.

개인 공간 (Personal)기관에 속하지 않은 사용자의 공간입니다. 운영사와 관리자 계층이 없습니다.
팀 전환개인 공간과 고객사 공간 사이를 전환하는 메뉴입니다.
납품 형태클라우드 또는 온프레미스입니다. 운영사가 고객사를 생성할 때 설정하며, 고객사 화면에서는 읽기 전용으로 표시됩니다.
폐쇄망외부 연결이 차단된 환경입니다. 기관 내부 연결과 내부에 설치된 모델만 사용합니다.
제작 권한 등급고객사가 유닛을 직접 만들 수 있는지 정하는 설정입니다. 운영사가 사용만 또는 제작 가능 중에서 선택합니다.
유닛 제작 허용팀 단위의 제작 권한입니다. 고객사가 제작 가능 등급일 때만 설정할 수 있습니다.
유닛 카탈로그운영사가 납품에 사용하는 공용 유닛과 구성 프리셋 목록입니다. 유닛마다 배포할 고객사를 지정합니다.
배포운영사가 유닛을 고객사에 제공하는 작업입니다. 유닛을 배포하면 연결된 Tool도 함께 배포됩니다.
설치본온프레미스 설치 준비 상태를 확인하고 Root 계정을 고객사에 전달하는 운영사 전용 화면입니다.

유닛

용어설명
유닛어시웍스에서 실행되는 기능 단위입니다. Tool, Agent, Flow로 구분합니다.
Tool한 가지 기능을 수행하는 가장 작은 단위입니다. 언어 모델(LLM), 이미지 판독(VLM), 외부 API, MCP, DB, 자료 수집(Collector), 문서 적재(VDB Loader), 문서 검색(VDB) 중에서 종류를 선택합니다.
AgentOperator와 Loop를 함께 이르는 이름입니다. Agents 메뉴에서 관리합니다.
Operator요청에 맞는 Tool을 선택해 실행하고, 결과를 답변으로 작성하는 유닛입니다.
Loop컨테이너 작업 환경에서 파일을 만들고 코드를 실행하며 결과를 수정하는 유닛입니다. 사용할 자원과 작업 시간의 한도를 설정합니다.
Flow여러 유닛을 순서와 조건에 따라 연결한 작업 흐름입니다.

용어설명
앱 (Apps)팀원이 접속해 업무를 시작하는 화면입니다. 유닛을 연결해야 팀원에게 표시됩니다.
대화형대화로 업무를 요청하는 앱 유형입니다.
대화형 + 지도 (어시지오)대화 화면과 지도를 함께 표시하는 앱 유형입니다. 맵셋을 지정해 사용합니다.
실무 화면팀원이 사용하는 앱 화면입니다. 관리자는 앱 상세의 실무 화면 열기에서 미리 확인합니다.
Air고객사 사이트에 연결하는 위젯입니다. 유닛이 아닌 진입점(서비스 접속 방식)입니다.

신규 고객사 초기 설정하기

운영사는 다음 5단계에 따라 초기 설정을 진행합니다. 각 단계에서 설정한 내용을 다음 단계에서 사용하므로 순서대로 진행합니다.

고객사 생성하기

Root → Enterprises → 새 고객사

먼저 고객사를 생성합니다. 이때 설정한 납품 형태·폐쇄망 여부·제작 등급에 따라 이후 제공되는 화면과 기능이 달라집니다.

관리자 계정 발급하기

해당 고객사 → 계정 탭

고객사 운영을 담당할 관리자 계정을 발급합니다. 발급하면 임시 비밀번호가 바로 한 번만 보이고, 저장되지 않습니다. 관리자가 이 비밀번호로 어드민에 처음 로그인하면 바로 비밀번호 변경 화면이 뜹니다. 비밀번호를 잊었을 때도 Root에서는 초기화만 합니다. 새 임시 비밀번호를 발급해 전달하면 같은 순서로 바꿉니다.

해당 고객사 → 팀 탭

유닛은 팀 단위로 제공되므로, 유닛을 배포하기 전에 팀을 구성합니다.

팀에 유닛을 제공하려면 먼저 해당 유닛을 고객사에 배포해야 합니다. 유닛을 배포하면 연결된 툴도 함께 배포됩니다.

팀별 앱 지정하기

해당 고객사 → 팀 탭 → 팀 설정

팀마다 사용할 앱과 팀원, 알림 대상을 설정합니다. 팀원에게 보이는 유닛은 그 앱에 연결된 유닛입니다.

4단계와 5단계는 하는 일이 다릅니다. 4단계에서는 고객사(Enterprise)에 유닛을 배포하고, 5단계에서는 팀별로 사용할 앱을 지정합니다. 팀원에게 표시되는 유닛은 Apps에서 해당 앱에 연결한 유닛입니다.

설정 시 확인할 내용

권한과 배포 구조를 설정할 때 확인할 사항을 정리했습니다.

자료는 기관별로 분리해 관리합니다

문서 폴더와 오버레이맵은 소속 기관의 자료만 표시됩니다. 베이스맵은 운영사가 등록한 공통 목록에서 선택합니다. 운영사 계정으로 로그인하면 전체 고객사의 자료가 해당 고객사 이름과 함께 표시됩니다. 개인 공간에는 기관 자료가 제공되지 않으므로 빈 상태로 시작합니다.

기관 오버레이맵은 기관이 직접 등록합니다

기관은 Maps › 맵셋 선택 › 오버레이맵 파일 등록에서 기관 오버레이맵을 올립니다. 베이스맵과 공통 오버레이맵은 운영사가 Maps › 자료에서 등록합니다. 문서는 기관이 Storage에서 직접 올립니다.

유닛은 Tool · Agent · Flow로 구분됩니다

Agent에는 Operator와 Loop가 포함됩니다. Loop는 Operator가 호출하거나 단독으로 실행할 수 있습니다. Flow에서는 Operator에 연결해서만 사용합니다. Air는 유닛이 아닌 진입점이므로 APPS 메뉴에 있습니다.

주기적으로 추가되는 지도 자료는 카탈로그에서 검색합니다

위성영상처럼 주기적으로 추가되는 자료는 기간·영역(지도에서 그리기)·구름량으로 검색 범위를 좁혀 사용할 장면을 선택합니다. 해당 맵셋이 연결된 Operator를 실행하면 선택한 장면이 해당 시점의 지도로 표시됩니다.

배율별로 표시할 지도를 설정할 수 있습니다

맵셋의 배율 탭에서 확대·축소 범위를 제한하고, 배율별 베이스맵과 오버레이맵 표시 범위를 설정합니다. 예를 들어 축소 상태에서는 일반지도를, 확대 상태에서는 위성사진을 표시할 수 있습니다. 정보가 밀집된 자료는 확대 상태에서만 표시하도록 설정해 겹침을 줄입니다.

맵셋은 Operator와 지도 앱에 연결합니다

맵셋은 베이스맵과 오버레이맵을 묶은 설정입니다. 베이스맵은 운영사가 제공하는 고정 목록에서 여러 개를 선택할 수 있으며, 실행 화면에서 전환할 수 있습니다. 오버레이맵은 소속 기관의 자료와 운영사가 등록한 공통 자료에서 선택합니다. 기관별 자료는 Enterprise 간에 분리됩니다. 맵셋을 Operator에 연결하면 실행 화면의 배경지도와 참조 자료가 함께 설정됩니다. 대화형 + 지도 앱은 앱 상세에서 맵셋을 지정합니다. 맵셋을 연결하지 않으면 지도 없이 실행됩니다.

제작 권한은 Enterprise와 팀 단위로 설정됩니다

Enterprise의 제작 권한 등급을 먼저 제작 가능으로 설정한 뒤 팀별 제작 권한을 설정합니다. Enterprise가 사용만으로 설정된 경우에는 팀의 제작 권한을 활성화할 수 없습니다.

폐쇄망에서는 외부 연결이 제한됩니다

폐쇄망에서는 외부 연결이 제한됩니다. 내부 문서·데이터와 Enterprise 내부에 설치된 모델은 사용할 수 있습니다.

권한에 따라 조회 범위가 달라집니다

Monitoring과 Audit Log는 권한에 따라 조회 범위가 다릅니다. Root는 전체 Enterprise, Admin은 소속 Enterprise, Client는 본인 범위의 정보만 확인할 수 있습니다.

온프레미스 인수 후에는 운영사가 접근할 수 없습니다

온프레미스 환경에서는 Root 계정을 고객사에 전달하면 인수가 완료됩니다. 이후 운영사의 원격 접근이 불가능하므로 계정을 전달하기 전에 필요한 설정을 모두 확인합니다.
