권한별 사용 범위

권한사용 범위
관리자(팀장·운영 담당)유닛을 만들고 앱에 연결해 팀에 제공합니다. 팀원과 팀 설정, 실행 기록, 변경 이력을 관리합니다.
팀원소속 팀에 지정된 앱에서 대화로 업무를 요청합니다. 정기 실행을 예약하고 결과를 확인합니다.

왼쪽의 Tools, Agents, Flows는 유닛 제작 메뉴입니다. Enterprise의 제작 권한 등급이 제작 가능이고 팀 설정에서 제작 허용이 켜져 있을 때 표시됩니다.

유닛 종류

유닛은 어시웍스에서 실행되는 기능 단위입니다. 여러 유닛을 조합해 더 큰 기능을 구성할 수 있습니다. 유닛은 Tool, Agent, Flow로 구분되며, Agent에는 Operator와 Loop가 있습니다.

유닛역할
Tool모델 호출, 외부 API 호출, 문서 검색처럼 한 가지 기능을 수행하는 가장 작은 단위입니다.
Operator요청에 따라 장착된 툴 중 필요한 툴을 실행하고 답변을 작성합니다. Agents 메뉴에서 관리합니다.
Loop컨테이너 작업 환경에서 파일을 만들거나 코드를 실행합니다. Agents 메뉴에서 관리합니다.
Flow여러 유닛을 순서대로 연결해 하나의 작업 흐름으로 실행합니다.

만든 유닛은 앱에 연결해야 팀원 화면에 표시됩니다. 앱은 팀원이 접속해 업무를 시작하는 화면입니다.

유닛 예시: 시설물 점검

시설물 점검 업무를 예로 들면 유닛별 역할은 다음과 같습니다.

Tool: 사진 한 장에서 파손 여부 확인하기

시설물 사진을 입력받아 난간이나 표지판의 파손 여부를 분석합니다.

사진 분석이라는 한 가지 기능을 수행합니다. 점검 이력을 조회하거나 담당자를 찾는 기능은 각각 다른 Tool로 만듭니다.

Operator: 현장 상황에 맞춰 필요한 정보를 확인하기

담당자가 사진과 함께 다음과 같이 요청합니다. "이 난간은 보수가 필요할까요? 이전에도 문제가 있었는지 확인해 주세요."

Operator는 사진 분석 Tool과 점검 이력 조회 Tool을 사용해 현재 상태와 이전 기록을 확인합니다. 확인한 내용을 종합해 담당자가 판단할 수 있도록 안내합니다.

요청에 따라 필요한 Tool을 선택해 실행하는 역할입니다.

Flow: 접수된 점검 자료를 정해진 절차로 처리하기

점검 자료가 접수되면 다음 순서로 처리합니다.

사진 분석 › 이전 점검 이력 조회 › 점검 결과 요약 › 보고서 작성

파손이 발견된 경우에만 담당자 확인 단계로 넘어가도록 조건을 설정할 수 있습니다.

여러 유닛을 연결해 정해진 순서와 조건에 따라 업무를 처리하는 역할입니다.

Loop: 여러 점검 파일을 정리해 보고서 작성하기

담당자가 다음과 같이 요청합니다. "이번 달 점검 폴더의 사진과 엑셀 파일을 정리해서 시설별 보고서를 만들어 주세요."

Loop는 폴더의 파일 구성을 확인하고, 사진과 점검 기록을 연결하는 코드를 작성해 실행합니다. 실행 결과에 누락되거나 중복된 항목이 있으면 코드를 수정해 다시 실행합니다. 마지막으로 확인이 필요한 항목을 별도로 표시해 보고서 파일을 생성합니다.

파일과 코드를 다루며 실행·확인·수정을 반복하는 역할입니다.

처음부터 따라 하기

시설물 사진의 파손 여부와 이전 점검 이력을 함께 확인하는 현장 점검 도우미를 만들어 담당 팀원에게 제공하는 순서입니다. 자세한 사용 방법은 각 단계의 링크에서 확인합니다.

점검 이력 데이터를 연결합니다Connections의 기관 내부에서 점검 이력이 저장된 데이터 저장소를 추가합니다. 연결 추가하기

점검 이력 조회 툴을 만듭니다Tools에서 DB 툴을 만듭니다. 시설물 번호로 이전 점검 기록을 조회하는 툴입니다. Tool 만들기

실행 결과를 확인합니다Monitoring에서 실행 내역과 정확도를 확인합니다. 실행 기록 확인하기
팀원이 사진과 함께 질문합니다팀원은 앱 접속 주소로 로그인합니다. 사진을 올리고 질문을 입력하면 Operator가 답변합니다. 업무 요청하기

매달 접수되는 점검 자료를 정해진 순서로 처리하려면 Flow를 만든 뒤 Schedules에서 정기 실행을 예약합니다. 예시는 유닛 예시: 시설물 점검에서 확인합니다.

Tool, Operator, Loop, Flow를 만드는 방법입니다. 일반적으로 Tool을 먼저 만들고 Operator에 장착합니다. 여러 단계로 이루어진 작업은 Flow로 구성합니다.

Tool 만들기

UNITS › Tools
  1. 왼쪽 메뉴에서 Tools를 누릅니다. 기존 툴이 카드 목록으로 표시됩니다.
  2. 오른쪽 위 새 툴을 누릅니다. 새 툴 만들기 창이 열립니다.
  3. 이름과 설명을 입력합니다. 이름은 필수 항목입니다.
  4. 툴 종류를 선택합니다. 선택한 종류에 따라 아래 입력 항목이 달라집니다.
  5. 선택한 툴 종류에 맞게 모델, 프롬프트, 입력 필드, 출력 필드 등을 설정합니다.
  6. 생성을 누릅니다. 만든 툴이 목록 맨 앞에 표시됩니다.

툴 종류

종류용도
LLM언어 모델로 글을 작성하거나 요약합니다.
VLM이미지를 읽는 모델로 사진이나 영상 속 대상을 판독합니다.
API외부 API를 호출해 데이터를 가져옵니다.
MCPMCP 방식으로 연결된 외부 서비스의 기능을 실행합니다. 예: 메신저 알림 발송
DB데이터베이스의 데이터를 조회하거나 저장합니다.
Collector외부 자료를 수집해 Storage에 저장합니다.
VDB LoaderStorage의 문서를 VDB에 적재해 검색할 수 있도록 합니다.
VDBVDB에 적재된 내용에서 질문과 유사한 내용을 검색합니다.

종류별 입력 항목

종류입력 항목
LLM, VLM모델, User Prompt, 입력 필드, 출력 필드
VDB Loader, VDB임베딩 모델, 입력 필드, 출력 필드
그 밖의 종류입력 필드, 출력 필드

User Prompt에는 {{photo}}처럼 입력 필드 이름을 이중 중괄호로 감싸 입력합니다. 실행 시 해당 위치에 입력값이 들어갑니다. 입력 필드와 출력 필드는 추가를 누르면 항목이 하나씩 추가됩니다.

적재와 검색에는 같은 임베딩 모델을 사용해야 합니다. VDB Loader 툴과 VDB 툴의 임베딩 모델이 다르면 올바른 검색 결과를 얻을 수 없습니다. 임베딩 모델을 변경하면 폴더를 다시 적재합니다.

입력을 마치고 생성을 누르면 만든 툴이 목록 맨 앞에 표시됩니다.

Tool 수정·삭제하기

목록에서 카드를 누르면 툴 편집 창이 열립니다. 내용을 수정한 뒤 저장을 누릅니다.

카드에 마우스를 올리면 오른쪽 위에 삭제 버튼이 표시됩니다. 삭제 버튼을 누르면 확인 창이 열립니다. 확인 창에는 이 툴을 사용하는 Operator와 Flow에서도 연결이 해제된다는 안내가 표시됩니다. 삭제를 누르면 툴이 목록에서 삭제됩니다.

Operator 만들기

UNITS › Agents › Operators
  1. 왼쪽 메뉴에서 Agents 아래 Operators를 누릅니다.
  2. 목록 위의 + 버튼을 누릅니다. 새 오퍼레이터 창이 열립니다.
  3. 아래 표를 참고해 항목을 입력합니다.
  4. 생성을 누릅니다.
항목입력 방법
이름, 설명Operator의 이름과 수행할 작업을 한 줄로 입력합니다.
모델답변을 작성할 모델을 선택합니다.
맵셋지도 없이 사용하려면 사용 안 함을 선택합니다. 맵셋을 선택하면 해당 지도를 사용하는 화면에서 실행됩니다.
역할 지시문Operator가 맡을 역할과 지켜야 할 규칙을 입력합니다.
답변 스타일답변 길이와 형식을 입력합니다.
장착 툴툴 이름을 입력하고 Enter를 누르면 툴이 장착됩니다. 실행할 때는 장착한 툴 중 요청에 필요한 툴만 실행됩니다.

Operator 시험 실행하기

  1. 목록에서 Operator를 선택합니다. 화면 가운데에 사용 플로우, 장착 툴, 입력 필드, 출력 필드의 수와 최근 실행 내역이 표시됩니다.
  2. 실행을 누릅니다. 실행 창이 열립니다.
  3. 아래 입력창에 메시지를 입력하고 Enter를 누릅니다. 줄을 바꾸려면 Shift+Enter를 누릅니다.

내용을 수정하려면 상세 화면에서 편집을 누릅니다. 수정한 내용을 저장하면 새 버전이 생성됩니다.

Loop 만들기

UNITS › Agents › Loops

Loop는 정해진 자원 한도 안에서 모델이 여러 차례 작업을 반복하는 유닛입니다. 코드 수정, 문서 생성처럼 여러 단계가 필요한 작업에 사용합니다.

  1. 왼쪽 메뉴에서 Agents 아래 Loops를 누릅니다.
  2. 오른쪽 위 New Loop를 누릅니다.
  3. Common에 Name을 입력하고 Space를 선택합니다.
  4. Resources에서 작업에 사용할 CPU, MEM, DISK, GPU와 최대 작업 시간(MAX TIME)을 선택합니다.
  5. Backend LLM에서 Mode와 Model을 선택합니다. Persona는 비워 둘 수 있습니다.
  6. 오른쪽 Summary에서 설정을 확인하고 Create Loop를 누릅니다.
Mode동작
Conversational대화에서 받은 요청을 하나씩 처리합니다.
Autonomous목표를 입력하면 필요한 단계를 스스로 정해 순서대로 진행합니다.
Plan작업 계획을 먼저 작성한 뒤 계획에 따라 진행합니다.

Use in automation을 켜면 Schedules와 Flow에서 이 Loop를 선택할 수 있습니다.

Loop 작업 확인하기

  1. Loops 목록에서 Loop의 Open을 누릅니다.
  2. Workspace에서 라운드별 진행 상황과 작업 기록을 확인합니다. 오른쪽에서 Editor, Terminal, Files 중 확인할 화면을 선택합니다.
  3. Connect를 누릅니다. 외부에서 이 Loop를 호출하는 주소(HTTP endpoint), MCP 도구 이름, 입력 형식, 호출 예시가 표시됩니다.

Flow 만들기

UNITS › Flows
  1. 왼쪽 메뉴에서 Flows를 누릅니다.
  2. 오른쪽 위 새 플로우를 누릅니다. 편집 화면이 열립니다.
  3. 왼쪽 아래 노드 추가를 누르고 추가할 노드를 선택합니다.
  4. Operator나 Tool을 선택하면 오른쪽에 선택 목록이 열립니다. 사용할 유닛을 선택합니다.
  5. 노드의 연결점을 다음 노드로 끌어 연결합니다. 노드는 연결된 순서대로 실행됩니다.
  6. 노드를 누르면 오른쪽에 설정이 표시됩니다. 이름과 노드별 항목을 입력합니다.
  7. 오른쪽 위 저장을 누릅니다.
노드용도
Input외부에서 데이터를 받는 시작점입니다.
Output최종 결과를 출력합니다.
Branch조건식에 따라 다음에 실행할 노드를 결정합니다.
Operator선택한 Operator를 실행합니다.
Tool선택한 Tool을 실행합니다.

Flow에서 Loop는 Operator 노드에 연결해 사용합니다.

Flow 실행하기

  1. 편집 화면 위쪽에서 실행 보기로 전환합니다.
  2. 아래 입력창에 질문을 입력합니다. 입력한 질문으로 Flow가 실행됩니다.
  3. 노드별 진행 상황과 결과가 대화 형태로 표시됩니다. 생성된 파일은 산출물에서 확인합니다.

만든 유닛을 팀원에게 제공하는 방법입니다. 유닛을 앱에 연결하고 팀에 해당 앱을 지정하면, 팀원은 앱에서 연결된 유닛을 사용할 수 있습니다.

앱 만들기

APPS › Apps
  1. 왼쪽 메뉴에서 Apps를 누릅니다.
  2. 오른쪽 위 앱 만들기를 누릅니다.
  3. 앱 이름을 입력합니다. 20자까지 입력할 수 있습니다.
  4. 화면 형태를 선택합니다. 지도 없이 대화로만 사용하려면 대화형을 선택합니다.
  5. 만들기를 누릅니다.

앱에 유닛 연결하기

  1. Apps 목록에서 앱을 선택합니다.
  2. 연결 유닛에서 유닛 연결을 누르고 Operator나 Flow를 선택합니다.

여기서 연결한 유닛만 팀원에게 표시됩니다. 팀 설정에서는 유닛을 다시 선택하지 않습니다.

항목내용
접속 주소팀원이 앱에 로그인하는 주소입니다. 팀원은 관리자 화면을 거치지 않고 이 주소로 앱에 접속합니다.

유닛이 사용할 문서와 지도 자료, 외부 연결을 관리합니다.

문서 올리기

WORKSPACE › Resources › Storage

Storage는 문서 원본을 폴더 단위로 보관합니다. 폴더의 문서를 VDB에 적재하면 유닛이 검색에 사용할 수 있습니다.

  1. 왼쪽 메뉴에서 Resources 아래 Storage를 누릅니다.
  2. 오른쪽 위 새 폴더를 누릅니다.
  3. 폴더 이름과 설명을 입력하고 만들기를 누릅니다.
  4. 목록에서 만든 폴더를 선택합니다.
  5. 오른쪽 위 문서 올리기를 누르고 파일을 선택합니다. 여러 파일을 한 번에 선택할 수 있습니다.

문서를 올리는 동안에는 업로드 중으로 표시되며, 완료되면 업로드 완료로 바뀝니다. 유닛은 업로드가 완료된 문서만 사용합니다.

문서를 추가하거나 삭제한 뒤에는 적재 툴을 다시 실행해야 변경 사항이 검색 결과에 반영됩니다. 폴더 상세의 연결된 유닛에서 적재 툴을 확인합니다.

적재 상태 확인하기

WORKSPACE › Resources › VDB

VDB는 Storage 폴더의 문서를 검색할 수 있도록 적재한 결과입니다. 이 화면에서는 적재 상태만 확인할 수 있으며, 실제 적재는 VDB Loader 툴이 수행합니다.

상태의미
원본과 같음Storage 폴더의 문서가 모두 적재되어 있습니다.
다시 적재 필요원본 폴더가 변경되었지만 변경 사항이 아직 적재되지 않았습니다. 검색에는 이전에 적재한 내용이 사용됩니다.
적재 중적재 툴이 실행 중입니다.
실패적재에 실패했습니다.

목록에서 VDB를 선택하면 원본 폴더, 적재 툴과 검색 툴, 이 VDB를 사용하는 Operator가 표시됩니다.

맵셋 만들기

WORKSPACE › Resources › Maps

맵셋은 배경지도(베이스맵)와 그 위에 겹쳐 표시하는 자료(오버레이맵)를 묶은 설정입니다. 지도를 사용하는 Operator와 앱에서 선택합니다. 대화형 앱만 사용하는 경우에는 맵셋이 필요하지 않습니다.

  1. Maps에서 오른쪽 위 새 맵셋을 누릅니다.
  2. 맵셋 이름을 입력하고 베이스맵과 오버레이맵을 선택합니다.
  3. 만들기를 누릅니다.

지도 화면 사용법은 어시지오(지도) 사용하기에서 확인합니다.

연결 추가하기

WORKSPACE › Connections

유닛이 사용하는 모델, 기관 시스템, 외부 서비스의 연결 정보를 관리합니다.

구분연결 종류
기관 내부내부 모델, 기관 시스템, 계정 명부, 데이터 저장소
외부 서비스모델 서비스 키, 외부 API 키, 저장소 토큰
  1. 왼쪽 메뉴에서 Connections를 누릅니다.
  2. 추가할 연결 종류 오른쪽의 + 추가를 누릅니다.
  3. 이름, 주소, 모델 이름 등 표시된 항목을 입력합니다. 입력 항목은 연결 종류에 따라 다릅니다.
  4. 연결 확인을 누르면 연결 상태가 표시됩니다.
  5. 연결이 정상이면 저장을 누릅니다.
폐쇄망 환경에서는 외부 서비스 연결을 추가할 수 없습니다. 기관 내부 연결과 Enterprise 내부에 설치된 모델은 사용할 수 있습니다.

  2. 오른쪽 위 새 예약을 누릅니다.
  3. 실행할 유닛 종류에서 Tool, Operator, Loop, Flow 중 하나를 선택합니다.
  4. 아래 선택란에서 실행할 유닛을 선택합니다.
  5. 실행 주기에서 주기를 선택하고, 아래 표를 참고해 값을 입력합니다.

매월날짜와 시각을 입력합니다. 예: 매월 1일 09:00

업무 요청하기

  1. 아래 입력창에 요청을 입력합니다. 예: "이 사진 속 난간에 파손이 있는지 확인하고 이전 점검 기록도 알려 주세요."

요청을 보내면 요청 내용에 맞는 유닛이 자동으로 실행됩니다. 팀원이 실행할 유닛을 직접 선택할 필요는 없습니다.

같은 대화에서 결과에 대해 추가로 질문할 수 있습니다.

사용할 수 있는 유닛 확인하기

입력창 위의 연결 유닛을 누르면 이 앱에서 사용할 수 있는 유닛 목록이 펼쳐집니다. 이 목록에서는 유닛을 직접 실행하지 않습니다.

지난 대화 찾기

  1. 왼쪽 대화 탭을 누릅니다. 지난 대화가 오늘, 어제, 지난 7일, 그 이전으로 묶여 표시됩니다.
  2. 대화를 선택하면 오른쪽에 내용이 열립니다.

예약 실행으로 생성된 대화에는 예약 표시가 나타납니다. 새로운 주제로 대화를 시작하려면 새 대화를 누릅니다.

대화 내역과 결과물은 30일간 보관됩니다. 계속 보관하려는 결과물은 보관 기간이 끝나기 전에 내려받습니다.

정기 실행 예약하기

  1. 왼쪽 예약 탭을 누릅니다.
  2. 예약 추가를 누릅니다.
  3. 실행할 유닛을 선택합니다.
  4. 주기에서 매일, 매주, 매월, 분기 중 하나를 선택합니다.
  5. 결과를 알림으로 받으려면 결과 알림 받기를 켭니다.
  6. 추가를 누릅니다.

예약 결과 확인하기

  1. 예약 탭에서 예약을 선택합니다.
  2. 상세 화면의 실행 결과에서 실행 시각과 결과 건수를 확인합니다.
  3. 결과를 선택하면 해당 실행의 결과를 담은 새 대화가 열립니다. 이 대화에서 결과에 대해 추가로 질문할 수 있습니다.

예약된 시각 전에 바로 실행하려면 지금 실행을 누릅니다. 예약 이름 옆 스위치를 누르면 예약이 켜지거나 꺼집니다.

예약 설정 변경하기

예약 상세에서 설정 변경을 누르면 예약 설정 창이 열립니다. 이름, 주기, 실행할 유닛, 결과 알림 받기를 변경하고 저장을 누릅니다.

예약을 삭제하려면 예약 설정 창에서 예약 삭제를 누른 뒤 확인 창에서 삭제를 누릅니다. 삭제한 예약은 복구할 수 없습니다.

파일 올리기

  1. 왼쪽 올린 파일 탭을 누릅니다. 입력창 오른쪽 클립 아이콘을 눌러도 이 탭이 열립니다.
  2. 끌어다 놓거나 눌러서 올리기 영역에 파일을 끌어다 놓거나, 영역을 눌러 파일을 선택합니다.

올린 파일은 분석에 사용할 수 있도록 처리됩니다. 처리 중에는 색인 중, 처리가 완료되면 준비됨, 처리에 실패하면 실패로 표시됩니다.

파일 종류지원 형식
영상.tif
도형.geojson, .shp, .gpkg
사진.zip
표.csv, .xlsx

올린 파일은 본인과 관리자만 볼 수 있습니다. 팀원과 공유할 자료는 관리자에게 공용 자료 등록을 요청합니다.

파일에 마우스를 올리면 삭제 버튼이 표시됩니다. 삭제 버튼을 누르고 확인 창에서 삭제를 누르면 파일이 목록에서 사라집니다. 삭제한 파일은 복구할 수 없습니다.

알림 확인하기

오른쪽 위 종 아이콘을 누르면 알림 목록이 열립니다. 예약 실행 완료, 새 탐지 결과 등의 알림이 표시됩니다.

지도를 함께 사용하는 앱(대화형 + 지도)에서 분석을 요청하고 결과를 지도에서 확인하는 방법입니다. 예약, 지난 대화, 파일 올리기, 알림은 대화형 화면 사용하기와 같습니다. 이 탭에서는 지도 관련 기능을 안내합니다.

화면 구성

위치주요 기능
왼쪽 탭예약, 대화, 올린 파일을 확인합니다.
가운데 지도분석 결과를 지도에서 확인합니다. 왼쪽 위에 위치 검색창과 오버레이맵, 오른쪽에 지도 도구, 아래쪽에 범례와 시점 비교, 상태 줄이 있습니다.
오른쪽 대화분석을 요청하고 답변을 확인합니다.
  • 탭 줄 오른쪽 끝의 화살표를 누르면 왼쪽 영역이 접힙니다.
  • 지도와 대화 사이의 세로선을 좌우로 끌면 대화 영역의 너비가 바뀝니다. 세로선을 두 번 누르면 기본 너비로 돌아갑니다.

분석 요청하기

  1. 오른쪽 대화 입력창에 분석할 내용을 입력합니다. 예: "지난주 들어온 시설물 점검 사진에서 파손 의심 지점을 찾아 주세요."
  2. 보내기 버튼을 누릅니다. 요청에 맞는 유닛이 자동으로 실행되고, 결과가 지도와 대화에 함께 표시됩니다.
  • 분석 범위: 요청에서 분석 범위가 명확하지 않으면 이를 묻는 질문이 표시됩니다. 전체, 관리구역, 점검구역 중 필요한 범위를 선택합니다.
  • 집계 구간: 집계 구간이 필요한 분석은 기본값으로 실행되며, 적용된 구간이 답변에 표시됩니다. 다른 구간이 필요하면 같은 대화에서 "시설 종류별로 다시 보여 주세요"처럼 요청합니다.
  • 이어서 분석: 같은 대화에서 "그중에", "거기서"처럼 이어서 질문하면 직전 답변의 결과를 대상으로 분석합니다. 새 대화에서는 이전 결과가 이어지지 않습니다.

분석 결과 확인하기

답변 위의 요청에 맞춰 실행한 유닛에서 실행된 유닛과 결과 건수를 확인합니다. 결과 위치는 지도에 번호와 위험도 색으로 표시됩니다.

답변 아래 집계표의 열 제목을 누르면 그 열을 기준으로 정렬됩니다. 위치가 있는 행을 누르면 지도에서 해당 대상이 강조되고 그 위치로 이동합니다.

파일 형식용도
GPKG도형과 속성 정보가 들어 있는 파일입니다. QGIS 등 지리정보 프로그램에서 열 수 있습니다.
CSV, XLSX표 형태의 수치 데이터입니다. 엑셀 등 표 계산 프로그램에서 열 수 있습니다.

결과 파일은 답변 아래 내려받기에서 내려받습니다. 분석 종류에 따라 제공되는 형식이 다릅니다.

지도 이동하기

지도를 끌면 지도가 이동합니다. 마우스 휠을 돌리거나 오른쪽의 확대·축소 버튼을 누르면 배율이 바뀝니다. 초기 위치로를 누르면 맵셋에 설정된 위치와 배율로 돌아갑니다.

위치 검색하기

  1. 지도 왼쪽 위 검색창에 주소, 지번, 지명 또는 좌표를 입력합니다. 좌표는 위도와 경도를 쉼표로 구분해 입력합니다.
  2. 검색창 아래에 표시된 후보 중 원하는 위치를 누릅니다. 키보드의 위아래 화살표로 후보를 선택하고 Enter를 눌러도 됩니다.

지도가 선택한 위치로 이동하고, 해당 위치에 표시가 나타납니다. 검색창의 X를 누르면 표시가 사라집니다. 위치 검색 내용은 대화 기록에 저장되지 않습니다.

이전·다음 범위로 돌아가기

오른쪽의 이전 범위를 누르면 직전에 보던 위치와 배율로 돌아갑니다. 다음 범위를 누르면 이전 범위로 돌아가기 전의 화면으로 이동합니다. 이전 범위로 돌아간 뒤 지도를 새로 이동하면 다음 범위 기록이 삭제됩니다.

축척과 좌표 확인하기

지도 아래쪽 줄에 축척 막대, 마우스가 가리키는 위치의 좌표, 좌표계, 방위가 표시됩니다. 지도를 확대하거나 축소하면 축척도 함께 바뀝니다.

베이스맵과 오버레이맵 바꾸기

오른쪽 베이스맵 설정을 누르고 사용할 베이스맵을 선택합니다. 베이스맵만 바뀌고, 표시 중인 오버레이맵은 그대로 유지됩니다. 필요한 베이스맵이 목록에 없으면 관리자에게 맵셋 수정을 요청합니다.

오버레이맵은 관리구역이나 토양도처럼 베이스맵 위에 겹쳐 표시하는 자료입니다. 왼쪽 위 오버레이맵을 누르면 자료 목록이 열립니다. 자료 이름을 누를 때마다 해당 자료가 지도에 표시되거나 숨겨집니다. 이름 왼쪽의 색상은 지도에 표시되는 색과 같습니다.

지도 왼쪽 아래 범례에서 결과 색상의 의미를 확인합니다.

지도 도구 사용하기

오른쪽 지도 도구는 한 번에 하나만 사용할 수 있습니다. 도구를 켜면 지도 위쪽에 선택한 도구 이름과 종료 방법이 표시됩니다. 도구가 켜져 있는 동안에는 지도를 끌어도 지도가 이동하지 않습니다.

  • 되돌리기를 누르면 마지막으로 추가한 점이 취소됩니다.
  • 끝내기를 누르거나 Esc 키를 누르면 도구가 종료됩니다.

거리·면적 재기

  1. 오른쪽의 거리 재기 또는 면적 재기를 누릅니다.
  2. 지도를 눌러 측정할 지점에 점을 추가합니다.
  3. 마지막 점을 두 번 누릅니다. 측정이 끝나고 길이 또는 넓이가 표시됩니다.

그리기와 글자 메모

  • 그리기를 누르면 점, 선, 면을 선택하는 창이 열립니다. 모양을 선택하고 지도를 눌러 점을 추가합니다. 선과 면은 마지막 점을 두 번 누르면 그리기가 완료됩니다.
  • 글자 메모를 누르고 메모를 넣을 위치를 누릅니다. 내용을 입력하고 Enter를 누르면 메모가 지도에 표시됩니다.

그린 도형과 메모는 분석 결과와 다른 색으로 표시됩니다. 새로 분석을 요청해도 도형과 메모는 지도에 유지됩니다.

관심지점 등록하기

  1. 오른쪽의 관심지점을 누릅니다.
  2. 지도에서 등록할 위치를 누릅니다.
  3. 이름을 입력하고 Enter를 누릅니다.

선택한 위치에 별 모양 아이콘과 이름이 표시되고, 관심지점 버튼에 등록된 개수가 표시됩니다. 관심지점을 누르면 목록이 열립니다. 목록에서 이름을 누르면 지도가 해당 위치로 이동합니다.

지우기

지우기를 누른 뒤 도형이나 메모에 마우스를 올리면 삭제할 대상이 빨간색으로 표시됩니다. 대상을 누르면 해당 도형이나 메모가 삭제됩니다. 분석 결과는 지우기로 삭제되지 않습니다.

지도 이미지 저장하기

오른쪽 지도 이미지 저장을 누르면 현재 화면에 보이는 지도가 이미지 파일로 저장됩니다. 저장한 이미지에는 범례, 축척, 방위, 좌표계가 함께 표시됩니다.

촬영 시점별 영상 비교하기

같은 위치를 서로 다른 날짜에 촬영한 영상 두 장을 비교합니다.

  1. 지도 아래 가운데의 시점 비교를 켭니다. 지도에 비교 손잡이가 나타나고 아래에 두 영상의 날짜가 표시됩니다.
  2. 가운데 손잡이를 좌우로 끌면 두 영상의 경계가 이동합니다. 경계 왼쪽에는 이전 영상이, 오른쪽에는 이후 영상이 표시됩니다.
  3. 차이만 보기를 켜면 변화가 확인된 구역만 표시됩니다.
  4. 다른 영상과 비교하려면 영상 바꾸기를 누릅니다. 목록에서 영상의 이전 또는 이후를 누르면 해당 위치에 영상이 배치됩니다.

촬영일이 있는 영상만 비교할 수 있습니다. 촬영일이 없는 파일은 올린 파일 탭에서 촬영일을 입력합니다. 구름량이 높은 영상은 변화를 확인하기 어려우므로 다른 날짜의 영상을 선택합니다.

올린 파일을 지도에 표시하기

  1. 올린 파일 탭에서 상태가 준비됨인 파일을 찾습니다.
  2. 파일의 좌표계와 촬영일을 확인합니다. 좌표계는 자료의 위치를 지도에 표시하는 기준입니다.
  3. 지도에 올리기를 누르면 현재 대화의 지도에 파일이 표시됩니다.

표 자료(.csv, .xlsx)는 지도에 표시되지 않으며, 분석할 때 값을 대조하는 데 사용됩니다.

예약 결과를 지도에서 확인하기

  1. 예약 탭에서 예약을 선택합니다.
  2. 실행 결과에서 눌러서 지도와 대화로 보기를 누릅니다. 지도에 결과가 표시되고, 해당 실행의 결과를 담은 새 대화가 열립니다.

결과 해석 시 유의 사항

  • 의심 지점은 확정된 결과가 아닙니다. 그림자나 오염이 변화로 탐지될 수 있으므로 현장 확인 후 판정합니다.
  • 두 대상이 같은 위치에 표시되더라도 인과관계가 있다고 단정할 수 없습니다. 원인을 판단하려면 현장 확인이나 추가 자료가 필요합니다.
  • 구름에 가려진 부분이 변화로 탐지될 수 있습니다. 결과가 구름 모양과 비슷하면 원본 영상과 구름량을 확인하고 다른 날짜의 영상을 선택합니다.
  • 같은 자료가 다른 색으로 보이면 선택한 베이스맵을 확인합니다. 오버레이맵 색상은 자료별로 고정되어 있으며, 베이스맵에 따라 다르게 보일 수 있습니다.
화면은 시안 기준이며 실제 서비스 화면과 다를 수 있습니다. 이미지를 누르면 크게 볼 수 있습니다. 운영사, 고객사, 팀의 관계와 용어, 권한별 메뉴 구성, 신규 고객사 초기 설정 순서는 구조 및 개념 가이드에서 확인합니다.
