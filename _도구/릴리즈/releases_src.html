2026년 10월 23일

실무 화면은 앱으로, 분석은 지도에서

관리자는 만든 유닛을 앱에 연결해 팀에 나눠 주고, 실무자는 지도와 대화가 함께 있는 화면에서 바로 요청합니다. 정해 둔 요청은 예약해 두면 사람이 없어도 실행됩니다.

@@IMG:hero|어시지오 실무 화면. 왼쪽 예약·대화·올린 파일, 가운데 지도, 오른쪽 대화@@

앱으로 실무 화면을 만들어 나눠 줍니다

실무자가 접속하는 화면을 앱으로 만듭니다. 화면 구성을 대화형 또는 대화형 + 지도 중에서 고르고, 지도형이면 맵셋을 연결합니다. 앱마다 전용 접속 주소가 생기고, 연결한 유닛만 실무자에게 보입니다.

입력창 예시 질문과 보고서 서식도 앱에서 정합니다. 서식에 표시자를 적어 두면 그 자리에 분석 결과가 채워집니다.

@@IMG:apps|Apps에서 앱의 화면 구성, 접속 주소, 연결 유닛, 보고서 서식을 정합니다@@

지도에서 찾고, 재고, 비교합니다

지도 위에 GIS 기본 도구를 넣었습니다. 주소나 좌표로 위치를 찾고, 거리와 면적을 재고, 점·선·면과 글자 메모를 남깁니다. 관심지점을 등록해 두면 목록에서 바로 찾아갑니다. 지금 보는 지도는 범례와 축척을 넣어 이미지로 저장합니다.

시점 비교를 켜면 촬영일이 다른 영상 두 장을 좌우로 겹쳐 봅니다. 가운데 손잡이를 끌어 경계를 옮깁니다.

@@IMG:compare|시점 비교. 이전 영상과 이후 영상을 좌우로 겹쳐 봅니다@@

정해 둔 요청을 주기마다 실행합니다

실행할 유닛과 요청 내용, 주기와 시각을 정해 예약합니다. 실행이 끝나면 오른쪽 위 종에 알림이 오고, 결과는 지도와 대화로 다시 열어 봅니다.

@@IMG:schedule|예약 추가 창. 실행할 유닛, 요청 내용, 주기와 시각, 결과 알림 받기@@

Operator가 쓸 도구를 먼저 고릅니다

Operator에 도구 호출 기법을 추가했습니다. 판정 모델이 요청에 맞는 도구를 먼저 고르고, 실행 모델은 고른 도구만 받아 답합니다. 두 모델은 따로 지정합니다. 지도용 Operator는 Geo 최적 구성 프리셋으로 한 번에 설정합니다.

@@IMG:operator|새 Operator 만들기. 도구 호출 기법, 실행 모델, 도구 판정 모델@@

그 밖의 개선

  • 관리자 메뉴를 APPS, UNITS, WORKSPACE, RECORDS 네 묶음으로 정리했습니다.
  • Maps에서 맵셋 지역의 지형(DEM)과 도로·하천·건물 오버레이맵을 자동으로 채웁니다.
  • Storage를 팀 폴더와 내 폴더로 나눴습니다.
  • Tool을 지울 때 확인 창이 뜨고, 그 Tool을 쓰던 Operator와 Flow에서도 빠진다고 알려 줍니다.
