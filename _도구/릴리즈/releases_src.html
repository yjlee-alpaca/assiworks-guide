앱 구성, 지도 분석 도구, 예약 실행 추가

관리자는 유닛을 연결한 앱을 구성해 팀에 제공합니다. 팀원은 지도와 대화를 함께 표시하는 화면에서 업무를 요청합니다. 반복하는 요청은 예약하면 정해진 시간에 자동으로 실행됩니다.

@@IMG:hero|어시지오 실무 화면. 왼쪽 예약·대화·올린 파일, 가운데 지도, 오른쪽 대화@@

앱을 구성해 팀에 제공합니다

팀원이 접속하는 화면을 앱으로 구성합니다. 화면 구성은 대화형과 대화형 + 지도 중에서 선택하며, 대화형 + 지도 앱에는 맵셋을 연결합니다. 앱마다 전용 접속 주소가 발급되고, 팀원에게는 앱에 연결한 유닛만 표시됩니다.

입력창에 표시할 예시 질문과 보고서 서식도 앱에서 설정합니다. 보고서 서식에 표시자를 넣으면 해당 위치에 분석 결과가 입력됩니다.

@@IMG:apps|Apps에서 앱의 화면 구성, 접속 주소, 연결 유닛, 보고서 서식을 설정합니다@@

지도에 GIS 기본 도구와 시점 비교를 추가했습니다

지도 화면에 GIS 기본 도구를 추가했습니다. 사용자는 다음 작업을 할 수 있습니다.

  • 주소나 좌표로 위치를 검색합니다.
  • 거리와 면적을 측정합니다.
  • 점, 선, 면과 텍스트 메모를 지도에 추가합니다.
  • 관심지점을 등록하고 목록에서 해당 위치로 이동합니다.
  • 현재 지도를 범례와 축척이 포함된 이미지로 저장합니다.

시점 비교를 켜면 촬영일이 다른 영상 두 장이 좌우로 겹쳐 표시됩니다. 가운데 손잡이를 끌면 두 영상의 경계가 이동합니다.

@@IMG:compare|시점 비교. 이전 영상과 이후 영상을 좌우로 겹쳐 표시합니다@@

요청을 예약해 주기적으로 실행합니다

실행할 유닛, 요청 내용, 실행 주기와 시각을 지정해 예약합니다. 예약한 요청은 지정한 시간에 자동으로 실행됩니다. 실행이 완료되면 알림이 표시되며, 결과는 지도와 대화 화면에서 다시 확인할 수 있습니다.

@@IMG:schedule|예약 추가 창. 실행할 유닛, 요청 내용, 주기와 시각, 결과 알림 받기@@

Operator에 도구 호출 기법을 추가했습니다

도구 호출 기법을 사용하면 도구 판정 모델이 요청에 맞는 도구를 먼저 선택합니다. 실행 모델은 선택된 도구만 사용해 답변을 작성합니다. 도구 판정 모델과 실행 모델은 각각 지정합니다. 지도용 Operator는 Geo 최적 구성 프리셋을 선택하면 필요한 설정이 한 번에 적용됩니다.

@@IMG:operator|새 Operator 만들기. 도구 호출 기법, 실행 모델, 도구 판정 모델@@

그 밖의 개선

  • 관리자 메뉴를 APPS, UNITS, WORKSPACE, RECORDS 네 그룹으로 재구성했습니다.
  • Maps에서 맵셋 지역의 지형(DEM)과 도로·하천·건물 오버레이맵이 자동으로 추가됩니다.
  • Storage를 팀 폴더와 내 폴더로 구분했습니다.
  • Tool을 삭제하면 확인 창이 표시됩니다. 확인 창에는 해당 Tool을 사용하는 Operator와 Flow에서도 연결이 해제된다는 안내를 표시합니다.
